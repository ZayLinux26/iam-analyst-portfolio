## What I'm Building

A ten-project portfolio covering the full IAM stack, anchored around a single fictional healthcare organization — **Meridian Health Partners** — so the work reads like a year of IAM operations at one company, not ten disconnected labs. Healthcare framing is deliberate: HIPAA forces strict least-privilege enforcement and audit-ready evidence, which are the standards I want my work judged against.
